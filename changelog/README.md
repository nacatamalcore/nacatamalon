# Earlier releases

One file per release that has been followed by another, named after its version (`0.1.7.md`), newest
first when listed. The current release and anything not yet released are in
[../CHANGELOG.md](../CHANGELOG.md).

When a release is published, its section moves out of `CHANGELOG.md` into a file here, unchanged, and
the `Unreleased` section there becomes the new release.

Releases before 0.1.7 have no notes.
